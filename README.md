## 📌 How These Projects Were Built

Each case study follows a consistent, professional structure:

1. Project Initiation (Charter, Business Case, Scope)  
2. Stakeholder Analysis  
3. Process Modeling (AS-IS → TO-BE → Gap)  
4. Requirements (BRD / FRD / NFR or AI Requirements)  
5. Agile Backlog (User Stories + Acceptance Criteria + Sample Jira CSV)  
6. UAT / Validation Scenarios  
7. Traceability, Risks, and Assumptions  
8. (Where relevant) KPI Frameworks, Dashboards, AI Decision Logic  

All repositories are written in clean Markdown, use Mermaid diagrams where helpful, and are ready to push directly to GitHub.
